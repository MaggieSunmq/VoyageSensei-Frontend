# cap-frontend-draft
Please refer to the following the list of pacakges need to be installed

frontend:
1. go to the frontend dir
2. npm install
(if npm is not installed on your device, please visit this site: https://docs.npmjs.com/downloading-and-installing-node-js-and-npm#overview)
3. Install the react-speech recognition pacakge: npm install react-speech-recognition
4. If the code does not compile and it shows some of the pacakages used is not installed, please follow the error message to install using npm command

How to run:

Frontend:
1. First make sure the backend is running
2. Go to the front end directory in a separate terminal window
2. Type npm start run

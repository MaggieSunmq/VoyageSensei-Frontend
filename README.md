# cap-frontend-draft
Please refer to the following the list of pacakges need to be installed
backend:
1. pip3(pip) install Flask
2. pip3(pip) install Flask-CORS

frontend:
1. npm install react-router-dom
2. npm install leaflet react-leaflet
3. npm install openrouteservice-js
4. npm install axios

How to run:\\
Backend:
1. Go to the backend directory in terminal 
2. python3 (python) app.py 

Frontend:
1. Go to the front end directory in a seperate terminal window
2. npm start run

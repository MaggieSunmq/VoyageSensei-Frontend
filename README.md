# cap-frontend-draft
Please refer to the following the list of pacakges need to be installed
backend:
pip3(pip) install Flask
pip3(pip) install Flask-CORS

frontend:
npm install react-router-dom
npm install leaflet react-leaflet
npm install openrouteservice-js
npm install axios

How to run:
Backend:
1. Go to the backend directory in terminal 
2. python3 (python) app.py 

Frontend:
1. Go to the front end directory in a seperate terminal window
2. npm start run
